# HTx Pain Institute — website

Marketing site for HTx Pain Institute (Houston and Humble, TX), built with Next.js App Router.

## Stack

- Next.js 16 (App Router, Turbopack), React 19, TypeScript
- Tailwind CSS v4 — brand tokens live in `src/app/globals.css`
- framer-motion for the tilt cards and the scroll-drawn line on the homepage
- `next/font` for Inter and Cormorant Garamond

## Scripts

```bash
npm run dev     # local dev server
npm run build   # production build (regenerates sitemap dates first)
npm run start   # serve the production build
npm run lint    # eslint
```

## Where things live

- `src/lib/nav.ts` — practice facts (name, phone, email, hours, both offices) and every nav list. Header, footer, JSON-LD, contact and location pages all read from here.
- `src/lib/condition-details.ts`, `service-details.ts`, `location-details.ts` — all copy for the condition, service and city pages. Each route under `src/app/<slug>/page.tsx` is a thin wrapper that picks one entry and renders the matching template in `src/components`.
- `src/lib/conditions.ts`, `services.ts` — the card lists that feed the hubs and the header menus.
- `src/lib/insurance.ts` — accepted plans, shared by `/insurance` and `/patients`.
- `src/lib/last-modified.ts` — generated by `scripts/last-modified.mjs` (runs before every build) from git history and committed, so git-less build hosts still have it; feeds `sitemap.xml`.
- `src/lib/site.ts` — the canonical origin, and the only place it is written. Every canonical, OG url, sitemap entry, robots directive and JSON-LD `@id` derives from it.
- `src/lib/analytics.ts` — the Google Tag Manager container and Google Ads IDs, plus the snippets the root layout renders.
- `src/lib/legacy-urls.ts` — old htxpaincare.com paths that this site spells differently, used by the domain redirects in `next.config.ts`.
- `public/images` — all photos, referenced by bare filename from the data files.

## Notes

- Appointment booking is Nimblr's embedded scheduler (URLs in `src/lib/scheduling.ts`); the contact form opens the visitor's email client (`mailto:`). There is no server-side form handling.
- `/appointment-confirmed` is where Nimblr returns a patient after a booking. It is `noindex`, excluded from the sitemap, and pushes an `appointment_confirmed` event to the dataLayer — that event, not the URL path, is what the Google Ads conversion trigger in GTM should fire on.
- `/blog` and every `/blog/*` URL redirect to the homepage until real posts exist (see `next.config.ts`). The blog files are kept in `src/app/blog`, and carry titles and excerpts only — no article bodies.
- Google Tag Manager and the Google Ads tag are rendered as literal `<script>` elements in the root layout's `<head>` rather than through `next/script`. In the App Router `strategy="beforeInteractive"` does not emit a real script tag; it queues the code into `self.__next_s` for the Next runtime to replay, which Google's install checks do not recognise.
- The canonical domain is `htxpaininstitute.com`. `htxpaincare.com` (and `www.`) 301 to it, per-path where the two sites spell a URL differently; both domains must stay pointed at this Vercel project for those rules to run.
